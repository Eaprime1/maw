# Prima template placeholders

Files from the prima terminal template that carry no Maw material yet. They
were moved here unchanged on 2026-11-22 so the repo root shows what is
actually the Maw. Nothing was deleted; `git log --follow <file>` shows each
file's history from its original path.

| Folder | Was at | What it is |
| --- | --- | --- |
| `quests/` | `quests/` (except `000-thee-the-door.md`) | Quest schema, quest README, example arc |
| `world/` | `world/` (except `the-the.md`) | Lore and factions placeholders |
| `guides/` | `guides/` | Player getting-started guide |
| `seeds/` | `seeds/` | Termux bootstrap and package list |
| `unexusi/` | `unexusi/` | Player identity / BBS connection spec |

Paths inside these files still point at their old locations; they are kept
as found. If a piece is wanted again, move it back.
